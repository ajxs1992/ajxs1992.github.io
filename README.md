# Welcome MOTD (sample)

Tiny original AMX Mod X plugin. Not FreeNova. Not a leak.

## Install

1. Compile `welcome_motd.sma` with AMXX 1.10.
2. Put `welcome_motd.amxx` in `addons/amxmodx/plugins/`.
3. Add `welcome_motd.amxx` to `plugins.ini`.
4. Copy `welcome_motd.txt` to `addons/amxmodx/configs/`.
5. `amx_welcome_motd 1`

This is the kind of **Basic $10** Fiverr deliverable (source + compiled + 1 revision).
